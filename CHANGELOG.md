# Changelog

## 0.2.0 — 2026-10-01

- Removed the vault Git repository and branch requirements.
- Added on-device related-note search through the Obsidian vault API.
- Added configurable context limits and excluded folders.
- Started Cursor agents without a repository.
- Moved the Cursor credential to Obsidian SecretStorage.
- Requires Obsidian 1.13.0 so settings appear in settings search.
- Stores chat history with Obsidian's vault-scoped storage.
- Documented the current Claude Code and Cursor SSO limitations.

## 0.1.0 — 2026-10-01

- Initial mobile chat panel backed by Cursor cloud agents.
